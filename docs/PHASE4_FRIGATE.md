## 2. Что нужно сделать

### 2.1 `frigate_bridge.py` — мост событий

Подписка через `homeassistant.components.mqtt.async_subscribe` на
`<prefix>/tracked_object_update`, фильтр `type == "face"`.

**Это правильный топик, и выбран он не случайно.** В `frigate/events` то же имя лежит
в `sub_label` как **список `[имя, score]`**, а в событии `type: "new"` его ещё нет —
распознавание идёт после детекции человека. `tracked_object_update` плоский, и `name`
в нём обычная строка.

⚠️ **Шинного события `frigate_event` в Home Assistant не существует.** Вокруг него
много неверных советов в сообществе. Работать только с MQTT и сущностями.

В `manifest.json` **нужно добавить** `"after_dependencies": ["mqtt", "frigate"]` —
сейчас его там нет (проверено). `after_dependencies`, а не `dependencies`: мост
опционален и выключен по умолчанию, и интеграция обязана грузиться на инсталляции,
где MQTT не настроен вовсе.

### 2.2 Обогащённое событие

Ложится в тот же `loki_event`, что и звонок:

```yaml
event_type: loki_event
data:
  type: face_recognized
  device_id: 123
  device_name: "Центральный вход"
  entity_id: camera.<дверь>
  name: "Имя"
  score: 0.92
  frigate_camera: "entrance"
  frigate_event_id: "1712345678.123456-abcdef"
  call_id: "…"        # только если звонок был в пределах окна корреляции
```

### 2.3 Сущность `event.<дверь>_face`

`event_types: ["recognized", "unknown"]`, только для дверей, попавших в карту камер.
Рядом с уже существующей `event.<дверь>_doorbell`.

### 2.4 Карта камер в options flow

`OPT_FRIGATE_CAMERA_MAP`: камера Frigate → числовой `device_id` двери Loki.

⚠️ В форме опций сохранять `{**options, **user_input}`, а не `user_input`:
`OPT_SIP_ENABLED` пишется переключателем и в форме не показывается, так что замена
словаря целиком **молча выключит SIP**. Это уже было.

### 2.5 Blueprint `face_notify.yaml`

Уведомляет. **Дверь не открывает** — см. §4.

## 3. Решения, которые уже приняты — не переоткрывать

| Решение | Почему |
|---|---|
| **Только Frigate.** Своего мониторинга RTSP нет | Frigate умеет распознавание лиц нативно с 0.16; писать своё — это ещё один процесс, который надо кормить потоком |
| **Coral не нужен и не поможет** | Frigate прямым текстом пишет, что Coral не даёт ускорения для enrichments; распознавание лиц на нём не запускается никогда. Нужен Intel iGPU + OpenVINO |
| **Требуется AVX+AVX2** | На x86 есть, на ARM нет. На Raspberry Pi распознавания лиц не будет |
| **1–2 двери, не все** | Упор не в ускоритель, а в декодирование: `detect: fps: 5` **не снижает** его стоимость, ffmpeg декодирует каждый кадр. 20+ потоков 1080p — несколько ядер круглосуточно и десятки мегабит постоянного трафика с чужого сервера |
| **Всегда через go2rtc** | Одно исходящее соединение к облаку разделяется между detect, record и просмотром |
| **Frigate 0.17.2+** | Закрыты шесть уязвимостей, включая утечку RTSP-кредов |
| **Корреляция по времени, а не запрос к API** | Нестабильный внутренний `POST /api/faces/recognize` остаётся запасным вариантом, если окажется, что `person` на кадре домофона не детектится |

## 4. Красная линия

**Автооткрытия двери по распознанному лицу в дизайне нет и быть не должно.**

Ни один backend не делает liveness — распознавание обманывается фотографией на экране
телефона. Подъездная дверь общая, и её открытие затрагивает соседей. Blueprint по лицу
**уведомляет**, а не открывает; открытие остаётся сознательным действием человека.

Если задача будет звучать как «сделай автооткрытие по лицу» — сначала сказать это
вслух и убедиться, что решение осознанное.

## 5. Открытый вопрос, с которого стоит начать

**Детектится ли `person` на кадре домофона?** Распознавание лиц запускается только на
кропе найденного человека, а у домофона кадр — голова и плечи крупным планом. Если
`person` не срабатывает, лиц не будет вовсе, и вся ветка меняется: придётся идти через
`POST /api/faces/recognize` по событию звонка.

Проверять это **до** написания моста: от ответа зависит вся архитектура фазы.

⚠️ На момент написания медиахост недоступен из-под VPN: таймаутятся и RTSP 8554, и
HTTP 8888, блокируется хост целиком. Пока это так, ни Frigate, ни проверку `person`
запустить нельзя. **Это первое, что надо разблокировать.**
