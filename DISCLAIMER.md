## 5. Обработка данных

5.1. ПО работает **локально** в составе Home Assistant Пользователя. Автор ПО не
получает, не хранит и не обрабатывает данные Пользователя: ни номер телефона, ни коды
подтверждения, ни токены доступа, ни видеопотоки, ни изображения.

5.2. Данные передаются исключительно между Home Assistant Пользователя и сервисами
оператора домофонной связи, отношения с которым регулируются договором между
Пользователем и оператором.

5.3. Учётные данные хранятся средствами Home Assistant в конфигурации Пользователя.
Обеспечение безопасности собственной инсталляции Home Assistant — зона
ответственности Пользователя.

## 6. Важное предупреждение о номере телефона

6.1. Сервис оператора допускает **только один активный сеанс на один номер телефона**.
Авторизация в ПО под номером, который уже используется в мобильном приложении
оператора, **приведёт к выходу из этого приложения**.

6.2. Настоятельно рекомендуется использовать для ПО **отдельный номер телефона**,
добавленный в список разрешённых номеров средствами официального приложения.

6.3. Автор не несёт ответственности за утрату доступа к официальному приложению
или к домофонной системе, вызванную несоблюдением пункта 6.2.
